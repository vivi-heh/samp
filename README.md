# Teacher's Day Memory Spaces

## Run locally

```powershell
python -m pip install -r requirements.txt
python app.py
```


Open `http://127.0.0.1:5000/` in the browser. Do not use VS Code Live Server for the login; Flask runs the PIN and private-message backend.
